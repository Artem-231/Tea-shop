# Чайная полка

Первая лабораторная работа по веб-программированию.
Магазин чая.

## Что можно делать

- Добавлять чай в корзину и удалять его.
- Менять количество упаковок кнопками + и −.
- Смотреть общую стоимость заказа.
- Обновлять страницу без потери корзины благодаря localStorage.
- Заполнять форму заказа и получать сообщение «Заказ создан!».

Страница адаптируется под размер экрана. После изменения количества можно
продолжать пользоваться кнопками с клавиатуры.

## Запуск

Открыть папку проекта в VS Code и запустить `index.html` через Live Server.

## Файлы

- `index.html` — каталог, корзина и форма.
- `styles.css` — стили и адаптивность.
- `script.js` — работа корзины, сохранение и обработка формы.
