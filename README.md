# Чайная полка

Мой магазин чая для первой лабораторной по веб-программированию.

[Открыть сайт](https://artem-231.github.io/Tea-shop/)

В каталоге можно оставить только зелёный, чёрный чай, улун или травяные сборы.
Упаковки добавляются кнопкой, а в корзине количество меняется через + и −.
Рядом показаны стоимость и общий вес чая. Максимум — 99 упаковок одного вида.

Перед оформлением видно состав заказа. Нужно заполнить имя, фамилию, телефон
и адрес. Кнопка «Вернуться к корзине» закрывает форму без удаления товаров.
После оформления появляется «Заказ создан!», количество упаковок и сумма.
Это учебная форма: настоящий заказ никуда не отправляется.

Корзина сохраняется в localStorage. Если браузер запрещает сохранение или
данные повреждены, на странице появляется пояснение.
