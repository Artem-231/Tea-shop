# Чайная полка

Первая лабораторная по веб-программированию - магазин чая.

Добавлены стили: зелёная шапка, карточки товаров и оформление формы.
На компьютере товары стоят в три колонки, на планшете в две, на телефоне в одну.
Для расположения элементов используются Grid и Flexbox.

Разметка находится в `index.html`, стили в `styles.css`.
Чтобы посмотреть страницу, надо открыть `index.html` в браузере.
Кнопки корзины пока не работают.
