# Чайная полка

Первая лабораторная по веб-программированию - магазин чая.

Можно выбрать чай, изменить количество упаковок или убрать товар из корзины.
Корзина сохраняется в localStorage и восстанавливается после обновления страницы.

Кнопка «Оформить заказ» открывает форму. Нужно заполнить имя, фамилию,
адрес и телефон. После отправки появляется «Заказ создан!», корзина очищается.

Запуск: открыть index.html в браузере.
Разметка - в `index.html`, стили - в `styles.css`, логика - в `script.js`.
