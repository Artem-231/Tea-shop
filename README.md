# Чайная полка

Первая лабораторная по веб-программированию - магазин чая.

Теперь можно добавлять чай в корзину, менять количество кнопками + и −,
удалять товары. Сумма пересчитывается, а в шапке показано общее количество упаковок.

- `index.html` - страница магазина;
- `styles.css` - оформление;
- `script.js` - работа корзины.

Запуск: открыть `index.html` в браузере.
После обновления страницы корзина пока очищается. Оформление заказа ещё не подключено.
